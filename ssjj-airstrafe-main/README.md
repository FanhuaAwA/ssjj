
# 生死狙击离线 / 刀战房间连跳测试工具。
 
> 本项目仅保证在**离线模式**或**单人房间测试**环境下可用。  
> 请勿用于任何联机、排位、匹配或多人对战场景。  
> 参与联机游戏可能会被**即刻踢出**，也可能导致**账号封禁**。  
> 本项目不提供、不保证任何绕过检测能力。

## 功能

- 空格键开关连跳功能
- FakeInput 落地跳
- 单人 / 离线测试使用
- 不保证联机可用

## Release 文件

发布包里的 **3 个文件放在同一个目录下**：

Bhop02Executor.exe
Bhop02.OnGroundAutoJump.dll
Bhop02Executor.exe.config

## 使用方法

1. 将 Release 中的 3 个文件放到同一个文件夹
2. **使用管理员权限运行** `BhopExecutor.exe`
3. 进入游戏后注入
4. 游戏内按 `Space`
   - 第一次按下：开启自动跳
   - 再按一次：关闭自动跳
